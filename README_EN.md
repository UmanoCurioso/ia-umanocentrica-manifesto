## What this project is

This repository contains the **Manifesto for Human-Centered AI**, a working document that maps the fundamental tensions of AI in the age of autonomous agents: asymmetries of memory, concentrations of power, cognitive dependency, information integrity, economic governance.

It is not a closed treaty. It is a **navigation map**, meant to be criticised, dismantled and improved.

## 🛠 How to contribute

Every argued critique is welcome. Read [**CONTRIBUTING.md**](CONTRIBUTING.md) for the method, acceptance criteria and declaration of interests.

In short:
1. Open an **Issue** to discuss a substantial change.
2. Open a **Pull Request** for punctual text changes.
3. Every substantial change produces a new version (v1.2, v1.3…).
4. The changelog is public: see [**CHANGELOG.md**](CHANGELOG.md).
