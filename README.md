## Cos'è questo progetto

Questo repository contiene il **Manifesto per l'IA Umanocentrica**, un documento di lavoro che mappa le tensioni fondamentali dell'IA nell'era degli agenti autonomi: asimmetrie di memoria, concentrazioni di potere, dipendenza cognitiva, integrità dell'informazione, governance economica.

Non è un trattato chiuso. È una **mappa di navigazione**, pensata per essere criticata, smontata e migliorata.

## 🛠 Come contribuire

Ogni critica argomentata è benvenuta. Leggi [**CONTRIBUTING.md**](CONTRIBUTING.md) per il metodo, i criteri di accettazione e la dichiarazione degli interessi.

In sintesi:
1. Apri una **Issue** per discutere una modifica sostanziale.
2. Apri una **Pull Request** per modifiche testuali puntuali.
3. Ogni modifica sostanziale produce una nuova versione (v1.2, v1.3…).
4. Il changelog è pubblico: vedi [**CHANGELOG.md**](CHANGELOG.md).
