## Qué es este proyecto

Este repositorio contiene el **Manifiesto por una IA Antropocéntrica**, un documento de trabajo que mapea las tensiones fundamentales de la IA en la era de los agentes autónomos: asimetrías de memoria, concentraciones de poder, dependencia cognitiva, integridad de la información, gobernanza económica.

No es un tratado cerrado. Es un **mapa de navegación**, pensado para ser criticado, desmontado y mejorado.

## 🛠 Cómo contribuir

Toda crítica argumentada es bienvenida. Lee [**CONTRIBUTING.md**](CONTRIBUTING.md) para conocer el método, los criterios de aceptación y la declaración de intereses.

En resumen:

1. Abre una **Issue** para discutir un cambio sustancial.
2. Abre una **Pull Request** para cambios textuales puntuales.
3. Todo cambio sustancial produce una nueva versión (v1.2, v1.3…).
4. El registro de cambios es público: consulta [**CHANGELOG.md**](CHANGELOG.md).
